# Sudoku Solver CV

Computer vision Sudoku solver using Python, OpenCV & TensorFlow.

## 🔧 Quick Start

```bash
pip install opencv-python tensorflow numpy matplotlib
python main.py
```

## 📌 What it does

- 📷 Captures Sudoku from image  
- 🔍 Detects digits using CNN  
- 🧩 Solves using backtracking  
- 📊 Displays solution overlay  

## 📁 Files

- `main.py` — Main app  
- `sudukoSolver.py` — Solver algorithm  
- `telkhatamhai.keras` — Digit recognition model  
- `utilities/utils.py` — Image processing  

## 📋 Requirements

- Clear image lighting  
- Standard printed Sudoku  
- Image in `photos/ew-suduko-img.png`  
- OpenCV + TensorFlow + Python
